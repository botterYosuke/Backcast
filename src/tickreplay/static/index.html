    Python 戦略

    ローカル保存。tick i の判断は tick i + 1 から有効です。

    Bundled RL は同梱モデルの判断を再生前に準備します。Load だけでは注文せず、Start 後の次 tick から売買します。

    RL Scalp Evolution v1 · 0株または100株 · 実際の保有数に応じて提案を選択

    初期化できない場合も、この欄からソースを選択・コピーできます。戦略ソースは ブラウザの localStorage に平文で保存されます。

    警告: 信頼できるコードだけを Load してください。Load を押すと Start より前にトップレベルの Python が直ちに実行されます。 Worker はセキュリティ sandbox ではなく、コードはネットワーク通信や同一オリジンのブラウザ機能を利用できます。

    戦略ワークスペースを初期化できませんでした。ソースの選択とコピーのみ利用できます。
